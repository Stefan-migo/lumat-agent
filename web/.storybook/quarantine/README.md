# Story quarantine

This directory holds stories that are duplicated or have retired ownership during the `ui-base` story triage. They remain available as reference material without being active Storybook owners.

`QUARANTINED — excluded from Storybook and Vitest`

Vitest excludes tests under `**/.storybook/quarantine/**/*.test.tsx`, and Storybook's `../src/stories/**/*.stories.tsx` glob does not discover stories moved here.
