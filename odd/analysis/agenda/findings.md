## Closed (not findings)

- **Tablet content clipping (~64px).** Owner: **capture artifact**, not a product bug. The capture
  tooling hid `#panel-shell-sidebar` without collapsing the shell rail grid track. Fixed in
  `web/scripts/capture-section.mjs`; no product finding.
- **Desktop 240px empty gutter.** Same capture artifact as above. Fixed in the capture tooling.
- **White element backgrounds.** Owner: advisory design rule (references may differ on palette; the
  design system wins, nearest colour, no white element backgrounds). Recorded as a forward constraint.
  No agenda element was found using a literal white/`#fff`; surfaces use `var(--surface)` /
  `var(--brand-bg-elevated)`. No code finding, consistent with the dashboard and usuarios records.
- **Mobile/tablet density.** Owner: the reference is compressed because it is AI-generated; the build
  must follow the design system's air and spacing. Recorded as a forward constraint for
  `agenda-006`/`agenda-008`, not a separate finding.
